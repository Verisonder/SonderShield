# SonderShield 1.1.0

## New: SonderShield for Windows
The first Windows version, in the same look as the phone app.

- **Blocks ads, trackers and malware** for every app on the PC, using the same block lists as the phone.
- **Firewall:** cut any app off the internet completely, on Wi-Fi and Ethernet.
- **Filter tab** with grouped lists and a live log, plus your own block and allow rules.
- **Built-in updates:** Settings › Updates installs new versions in place, with no reinstall.
- Optional start with Windows.

**To use it:** download `SonderShield-Windows-1.1.0.exe` and run it (a zip of the same file is there too). Windows asks for administrator rights, which it needs to change the PC's DNS and firewall. Then click the shield.

This is a first version: please report anything that doesn't work using the bug report on the Issues page. Not on Windows yet: HTTPS filtering, full tunnel and WireGuard, and languages other than English.
