# SonderShield 2.4.0

## Android
- **Data tab opens instantly:** the last numbers show straight away when you come back, today's usage loads first, and the plan and weekly chart are read in parallel. The cards animate in as soon as you arrive.
- The blue swoosh now sweeps in from the right.

## Windows
- **Firewall, app by app:** apps appear as tiles with their real icons, grouped into **Active**, **Recently edited** and **All**. Tap one to choose: allow, block incoming only, block local network, or block entirely.
- **Connections filters:** show all / allowed / blocked / direct IP, group by app or domain, sort by newest, most used or name. Each row opens a details panel with quick actions (app rules, block this address, copy).
- **Activity chart:** open connections and blocked lookups over the last 10 minutes or hour.
- **Fewer false "No queries" warnings:** Windows caches lookups, so quiet spells no longer trigger the banner.
- **Better diagnostic:** names the program holding port 53 when SonderShield can't use it, and warns when a browser's own secure DNS is bypassing blocking.
- The blue swoosh now sweeps in from the right, matching the phone.

Updating on Windows: Settings › Updates.
