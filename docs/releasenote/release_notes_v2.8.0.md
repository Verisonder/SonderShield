# SonderShield 2.8.0

## Android
- **Swipe between sections:** on Data (Usage, Apps, Rules) and Filter (Profiles, Lists, Log), swipe sideways to move between them. The header and chips stay in place.
- **Data plan, left today:** the daily tile now shows what's still free of today's share and counts down as you use mobile data. Today's share is set each midnight from what's left in your plan.
- **Data › Apps opens on Mobile.**
- **Smoother tab icons:** the Filter and Data icons animate a little slower.

## Windows and Linux
- No changes in this version.

Updating on Windows and Linux: Settings › Updates.
