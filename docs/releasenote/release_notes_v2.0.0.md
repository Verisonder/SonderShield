# SonderShield 2.0.0

## Android: Data Monitor
- **New Data tab** (replaces Rules): today's **mobile** and **Wi-Fi** usage, sent and received.
- **Monthly plan:** enter your plan's data and length once, then see what's left, the daily quota and when it ends.
- **This week:** a 7-day chart of mobile and Wi-Fi use.
- Needs Usage access once (the tab takes you to the right setting). Everything stays on the phone.
- **Rules** now live inside the Data tab.
- Settings icon is a gear now.

## Windows: firewall, like Portmaster
- **Connections:** every app's live internet connections, with the site each one goes to. Connections straight to an IP are flagged.
- **Per-app rules:** Allow, Block all, No incoming, or No LAN for each app.
- **Block by address or port** for every app.
- **Block all internet:** a panic switch that cuts off every app. SonderShield itself keeps working so you can switch it back.
- **Force DNS through SonderShield:** stops browsers and apps using their own DNS (other DNS servers, DNS-over-TLS, known DNS-over-HTTPS resolvers) to get around filtering.
- **DNS diagnostic:** if Windows isn't sending lookups to SonderShield, "See why" shows what each network adapter is really using and how to fix it.

## Windows: new look
- Home now uses the whole window: today's numbers with the all-time stats beside them, then the activity chart (24 hours / 7 days) and the top blocked sites, all animated like the phone.
- The shield shows it's starting up when you click it.
- Fixed: the DNS server menu closed when you moved the mouse.
- Settings icon is a gear.

Updating on Windows: Settings › Updates.
