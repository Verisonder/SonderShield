First release.

- System-wide ad, tracker and malware blocking through a local DNS-only VPN. No root.
- Block lists: StevenBlack, AdGuard DNS, URLhaus on by default; HaGeZi Pro, HaGeZi Threat Intelligence,
  HaGeZi Xiaomi tracking and OISD small available; custom lists by URL.
- Your own block and allow rules, and a domain test that shows which rule or list decides.
- Live DNS log with search and filters; block or allow straight from it.
- Per-app bypass.
- Encrypted DNS (DoH) to Cloudflare, Quad9, Google or AdGuard, plain DNS, or a custom server.
- Quick Settings tile, start on boot, always-on VPN, scheduled list updates on Wi-Fi.
