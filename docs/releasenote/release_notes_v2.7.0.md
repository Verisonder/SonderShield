# SonderShield 2.7.0

## Android
- **Data per app:** Data › Apps shows how much each app used — today, 7 days, 30 days or your plan period — on mobile, Wi-Fi or both. Tap an app for sent and received.
- **Animated tabs:** each icon in the bottom bar plays its own little move when you tap it.
- **Updates in the app:** Settings › Updates checks for new versions and installs them in one tap. A dot on Settings shows when one is out.
- The data cards no longer cut off "MB" on large numbers.

## Windows
- **Animated sidebar:** each icon plays its own move when you click it.
- A dot on Settings shows when a new version is out (checked by itself).
- After an update, protection turns back on by itself.

## Linux (new)
- **SonderShield for Linux** as an AppImage: make it executable and open it. It asks for your password once to install its background service, then adds itself to your app launcher.
- Same window and features as Windows: blocking for every app, Force DNS (also stops browsers' Cloudflare secure DNS), the panic switch, address and port blocks, live connections, profiles and updates.
- Per-app firewall rules aren't available on Linux.
- No password prompt on your desktop (e.g. bare Hyprland)? Run `sudo ./SonderShield-Linux-2.7.0-x86_64.AppImage --install` once.

Updating on Windows and Linux: Settings › Updates.
