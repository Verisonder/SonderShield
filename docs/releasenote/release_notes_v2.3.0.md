## Android
- **Data plan setup, like Data Monitor:** choose how the counter resets — **Daily**, **Monthly** or **Custom** dates — and set the data limit in MB or GB. The plan block shows what's left, a daily amount to stay within the limit, and when it resets or ends. Plans can be removed.
- **Always-on VPN:** when Android's Always-on VPN is set for SonderShield, Home says **Protection always on**, and tapping the shield (or the Quick Settings tile, or the widget) opens the phone's VPN settings instead of trying to turn it off.
- **System theme** now uses the original soft dark grey at night instead of pure black. **Default** stays pure black.
- Fixed: the Usage / Rules buttons were pushed too far right.

## Windows
- **More stats on Home:** data received and sent this session, active connections and active apps.
- **Network history:** Connections now has **Live** and **History**. History is a searchable record of every site each app connected to since protection turned on — how often, and whether it was blocked or a direct IP.
- **Home looks cleaner:** Today and All time sit in one panel under one swoosh, and the swoosh's ends are rounded.
- **System theme** uses the same soft dark grey as the phone. **Dark** stays pure black.
- Fixed: **See why** on the "Windows isn't sending its lookups" banner did nothing.

Updating on Windows: Settings › Updates.
